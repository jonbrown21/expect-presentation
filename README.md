A series of scripts that were used at the 2024 Mac Admins PSU Expect Presentation. 

## 🎤 Overview  
This repository contains the materials from the **“More to Expect than you may Expect”** presentation at the MacAdmins PSU 2024 conference.  
It is intended for macOS administrators and Apple device-management professionals who want to learn how to anticipate and handle device-management scenarios, and explore scripting workflows that extend what you might “expect”.

### What’s included  
- A PDF version of the slide deck: `More to Expect than you may Expect.pdf`  
- Supporting scripts and materials used in the talk: folders such as `Autopkg`, `Firmware`, `Salesforce_Dataloader`, etc.  
- A README (this document) explaining how to explore or reuse the content.

## 📝 Usage  
1. **Open the PDF slide deck** to review the full presentation.  
2. Browse the folders for each scripting example referenced in the deck.  
3. To run a script: open the folder, review the `README` or comments, set any environment-specific variables (e.g., MDM server URLs, credentials), and execute as appropriate (shell script, Python script, etc.).  
4. Adapt each example for your own environment—these are starting points, not full production tools.

## 🎯 Audience & Goals  
This content is aimed at macOS and Apple device-management professionals (including MacAdmins, IT Engineers, MDM specialists) who want to go *beyond the basics* and explore “what’s next” in automation, scripting, firmware management, and data-driven insights for a managed fleet.

## 📌 Key Take-aways  
- Expect the unexpected: i.e., device scenarios, firmware quirks, automation edge-cases.  
- Use scripting and data-driven methods to anticipate issues rather than just react.  
- Build modular, reusable scripts and workflows that integrate with your device-management infrastructure.  
- Contextualize your environment: your tools, fleet size, OS versions, MDM platform—these matter.

## 🚀 Requirements  
- A macOS environment (10.15+ recommended; Big Sur / Monterey / Ventura etc)  
- Basic familiarity with Terminal, shell scripting or Python  
- Access to a managed macOS device or test/dev environment  
- (Optional) MDM platform access (e.g., JAMF, Mosyle, Kandji) depending on which scripts you run
